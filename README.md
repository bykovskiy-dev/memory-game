# Memory Game

Emoji Memory Match — браузерная игра на поиск пар карточек.

## Описание

Игрок открывает карточки и ищет совпадающие эмодзи. Цель — найти все 8 пар за наименьшее число ходов. Результаты завершённых игр сохраняются в таблице лидеров (localStorage).

### Возможности

- поле 4×4 (16 карточек, 8 пар эмодзи);
- счётчики ходов и найденных пар;
- новая игра без перезагрузки страницы;
- модальное окно победы с итоговым числом ходов;
- таблица лидеров (топ-10) с сохранением в `localStorage`;
- адаптивная вёрстка.

## Технологии

- HTML
- CSS
- JavaScript (ES Modules)

## Локальный запуск

### Вариант 1: открыть в браузере

Откройте файл `index.html` в браузере (двойной клик или Drag & Drop во вкладку).

> Из‑за ES Modules некоторые браузеры могут блокировать скрипты при открытии через `file://`. В этом случае используйте Live Server.

### Вариант 2: Live Server (VS Code / Cursor)

1. Установите расширение **Live Server**.
2. Откройте `index.html`.
3. Нажмите **Open with Live Server** (или «Go Live» в статусбаре).
4. Игра откроется в браузере по адресу вроде `http://127.0.0.1:5500`.
